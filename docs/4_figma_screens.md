# 4. Спецификация экранов и макетов Figma EQUHUB

## 4.1 Полный перечень экранов приложения (16 экранов)

1. **Splash / Заставка**: Загрузка приложения, векторный логотип EQUHUB, проверкa JWT сессии.
2. **Login / Вход**: Форма ввода email/пароля, вход через OAuth (Яндекс, VK, Google), биометрия (FaceID / Fingerprint).
3. **Registration / Регистрация**: Пошаговый мастер создания аккаунта, верификация SMS/Email.
4. **Home / Лента Активности**: Верхний сторис-бар, рекомендуемые сообщества, агрегированный поток рекомендаций.
5. **Feed / Публикации**: Создание постов, загрузка медиафайлов в MinIO S3, реакция, комментарии и репосты.
6. **Marketplace / Маркетплейс**: Фильтры по категориям (Техника, Авто, Недвижимость), строка поиска и интерактивная карта.
7. **Product Card / Карточка товара**: Галерея медиа, блок безопасной сделки Escrow, рейтинг продавца и AI-оценка цены.
8. **Jobs / Раздел Работа**: Вкладки "Вакансии" и "Резюме", фильтры по зарплате и отраслям, быстрая кнопка отклика.
9. **Chat / Реалтайм Чат**: Текстовые сообщения через WebSockets, голосовые заметки, статус прочтения.
10. **Video Call / Видеосвязь**: WebRTC P2P видеозвонки с передачей аудио/видео сигнала через C++ ядро.
11. **Wallet / Внутренний Кошелек**: Рублевый баланс, история операций, пополнение через СБП, вывод средств.
12. **AI Assistant / AI Помощник**: Интерактивный генератор описаний, автоопределение категорий, проверка на спам.
13. **Notifications / Центр Уведомлений**: Системные пуш-уведомления, статусы безопасных сделок, отклики на вакансии.
14. **Search / Глобальный Поиск**: Полнотекстовый поиск Elasticsearch по всей платформе.
15. **Profile / Профиль**: Аватар, обложка, рейтинг, активность, список безопасных сделок и объявлений.
16. **Admin Panel / Панель Админа**: Мониторинг нагрузок, модерация жалоб, заблокированные пользователи, лог-терминал.
