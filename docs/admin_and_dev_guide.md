# Руководство администратора и разработчика EQUHUB

Настоящий документ предназначен для инженеров, DevOps-специалистов и администраторов платформы EQUHUB. Он содержит инструкции по локальному развертыванию, разработке, администрированию и мониторингу системы, соответствующий разделам 12, 14 и 15 Спецификации Требований (SRS).

---

## 1. Справочник команд для разработчика

### 1.1 Системные требования
* Node.js v20.x или выше
* Python v3.12.x или выше
* Docker & Docker Compose v2.x или выше

### 1.2 Начало работы
Склонируйте репозиторий и установите все зависимости для фронтенда и бэкенда:
```bash
# Установка npm-пакетов
npm install

# Установка Python-зависимостей (при наличии virtualenv)
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 1.3 Запуск сервера разработки
Запустите Next.js сервер для интерактивного дашборда:
```bash
npm run dev
```
Интерфейс будет доступен по адресу `http://localhost:3000`.

### 1.4 Проверка качества кода (Линтинг и типизация)
Перед отправкой изменений в репозиторий обязательно запустите статический анализатор типов:
```bash
npx tsc --noEmit
```

## 2. Команды тестирования

### 2.1 Запуск модульных тестов (Backend)
Запуск тестов Python:
```bash
pytest
```

### 2.2 Запуск Playwright верификации UI
Запустите проверку генератора звуков и скриншотирования:
```bash
python tests/verify_sound_gen.py
```

## 3. Руководство администратора по мониторингу

Для отслеживания работоспособности микросервисов в продакшне используются:
1. **Prometheus & Grafana:** Сбор метрик процессора, оперативной памяти, времени ответа API (p99 latency) и количества активных вебсокет-соединений.
2. **Jaeger Tracing:** Трассировка цепочки сквозных запросов между микросервисами (например, от API Gateway -> Vacancy Service -> Notification Service -> RabbitMQ).
3. **ELK Stack (Elasticsearch, Logstash, Kibana):** Централизованное логирование. Все микросервисы пишут логи в стандартный вывод (STDOUT) в формате JSON, которые агрегируются Logstash и индексируются в Elasticsearch.
