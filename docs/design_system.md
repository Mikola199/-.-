# Дизайн-система Единой цифровой платформы EQUHUB

Настоящий документ описывает визуальный стиль, палитру цветов, типографику и основные компоненты платформы EQUHUB, соответствующий разделу 11 и 15 Спецификации Требований (SRS).

---

## 1. Концепция дизайна
Визуальный стиль EQUHUB основан на концепции **Premium Minimalist Dark Mode** с использованием стекол (glassmorphism), тонких неоновых рамок с подсветкой (glowing border transitions) и глубокого темного фона, имитирующего бескрайний космос и передовые цифровые интерфейсы.

---

## 2. Цветовые CSS переменные (`app/globals.css`)

Платформа использует глобальную палитру CSS переменных для поддержания бренд-идентичности:

| Переменная | Значение | Описание визуальной роли |
| :--- | :--- | :--- |
| `--bg` | `#030610` | Глубокий космический черный фоновый цвет всего приложения. |
| `--surface` | `rgba(10, 15, 30, 0.7)` | Полупрозрачное матовое стекло (Glassmorphism) для карточек и панелей. |
| `--text` | `#f3f4f6` | Чистый, контрастный мягкий белый цвет для основного текста. |
| `--muted` | `#6b7280` | Сдержанный серый цвет для подзаголовков, дат и второстепенной информации. |
| `--accent` | `#06b6d4` | Яркий бирюзовый (cyan) неон для активных элементов, кнопок и статусов. |
| `--accent-purple` | `#8b5cf6` | Магический фиолетовый неон для резюме, специальных разделов и эффектов свечения. |
| `--border` | `rgba(255, 255, 255, 0.06)` | Сверхтонкая рамка для создания структуры интерфейса без визуального шума. |

---

## 3. Типографика

* **Основной шрифт:** `Inter`, `Segoe UI`, `system-ui`.
* **Заголовки (`h1`, `h2`):** Жирное начертание (font-weight: 700-800), легкий трекинг (letter-spacing: -0.02em).
* **Подзаголовки и статус-бары:** Моноширинный шрифт для отображения технических параметров и журналов реального времени: `Courier New`, `monospace`.

---

## 4. UI Компоненты

### 4.1 Эффект Стеклянной Панели (Glassmorphism Panel)
Реализуется с помощью CSS-свойств размытия заднего плана:
```css
.glass-panel {
  background: var(--surface);
  backdrop-filter: blur(16px);
  -webkit-backdrop-filter: blur(16px);
  border: 1px solid var(--border);
  border-radius: 16px;
  box-shadow: 0 8px 32px 0 rgba(0, 0, 0, 0.37);
}
```

### 4.2 Неоновые кнопки (Glowing Buttons)
Кнопки имеют плавный переход цвета и внешнее свечение при наведении (glowing shadows):
```css
.glow-btn {
  background: linear-gradient(135deg, var(--accent), var(--accent-purple));
  color: #fff;
  font-weight: 600;
  border-radius: 8px;
  border: none;
  box-shadow: 0 0 10px rgba(6, 182, 212, 0.2);
  transition: all 0.3s ease;
}
.glow-btn:hover {
  box-shadow: 0 0 20px rgba(6, 182, 212, 0.5), 0 0 30px rgba(139, 92, 246, 0.3);
  transform: translateY(-1px);
}
```
