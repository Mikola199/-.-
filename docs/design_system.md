# Руководство по дизайн-системе EQUHUB (Figma & UI System)

Настоящий документ содержит описание дизайн-системы, используемых CSS-переменных, правил типографики, компонентов и подходов к верстке Единой цифровой платформы **EQUHUB** в соответствии с Разделами 11 и 15 (Пункты 4 и 5) Требований к программному обеспечению (SRS).

---

## 1. Цветовая палитра (Color Palette)

Визуальное оформление EQUHUB основано на концепции **Premium Minimalist Dark Theme** с использованием эффектов матового стекла (glassmorphism), неонового свечения и тонких контрастных границ.

В файле `app/globals.css` определены следующие базовые CSS-переменные:

```css
:root {
  --bg: #05070f;                              /* Глубокий космический черный фон */
  --surface: rgba(13, 20, 38, 0.7);           /* Полупрозрачная подложка с эффектом стекла */
  --surface-opaque: #0c101f;                  /* Непрозрачный темный фон для контрастных блоков */
  --text: #f1f5f9;                            /* Светло-серый основной текст (High Emphasis) */
  --muted: #94a3b8;                           /* Приглушенный серый для подписей (Medium Emphasis) */
  --accent-blue: #3b82f6;                     /* Неоновый синий (акценты, ссылки, успешные состояния) */
  --accent-purple: #8b5cf6;                   /* Неоновый фиолетовый (основной бренд-акцент) */
  --accent-cyan: #06b6d4;                     /* Неоновый бирюзовый (маркеры новизны, кнопки "Работа") */
  --border: rgba(255, 255, 255, 0.08);        /* Тонкие полупрозрачные рамки */
  --border-glow: rgba(139, 92, 246, 0.25);    /* Свечение рамок при наведении */
  --shadow-glow: rgba(139, 92, 246, 0.15);    /* Мягкая фиолетовая тень-свечение */
}
```

## 2. Типографика (Typography)

Основной используемый шрифт — **Inter** (семейство шрифтов без засечек `system-ui, -apple-system, sans-serif`).

### Правила применения шрифтов:
* **Заголовки первого уровня (`H1`, логотип, экраны маркетплейса):**
  * Шрифт: `Inter`, Начертание: `800` (Extra Bold) или `700` (Bold).
  * Эффект: линейный градиент `linear-gradient(135deg, #3b82f6, #8b5cf6, #06b6d4)` с размытой тенью `text-shadow: 0 0 30px rgba(139, 92, 246, 0.4)`.
* **Заголовки разделов (`H2`, `.font-bold`):**
  * Шрифт: `Inter`, Начертание: `700` (Bold).
  * Размер: `1rem` (16px) до `1.5rem` (24px).
* **Основной текст со средней контрастностью (`.text-muted`):**
  * Цвет: `var(--muted)` (`#94a3b8`), Начертание: `400` (Regular) или `500` (Medium).
  * Размер: `0.75rem` (12px) до `0.875rem` (14px).
* **Моноширинный текст (Мониторинг логов, параметры звука):**
  * Семейство: `'Courier New', Courier, monospace`.
  * Размер: `10px` - `11px` для обеспечения компактности и читаемости системного вывода.

## 3. Компоненты интерфейса (UI Components)

### 3.1 Панели с эффектом стекла (`.glass-panel`)
Применяются в качестве карточек контента, боковых панелей управления и обрамления монитора архитектуры.
* **Свойства:**
  * Задний фон: `var(--surface)` с фильтром размытия `backdrop-filter: blur(16px)`.
  * Рамка: `1px solid var(--border)`.
  * Закругление углов: `24px` (для крупных блоков) или `16px` (для карточек объявлений `.phone-card`).
  * Тень: `0 8px 32px 0 rgba(0, 0, 0, 0.37)`.
  * Анимация при наведении (`:hover`): плавный переход (`transition: border-color 0.3s ease`) к фиолетовой рамке и свечению `shadow-glow`.

### 3.2 Кнопки с неоновым градиентом (`.glow-btn`, `.phone-btn-neon`)
* **Концепция:**
  * Градиент: `linear-gradient(135deg, var(--accent-blue), var(--accent-purple))`.
  * Тень: `0 4px 15px rgba(139, 92, 246, 0.4)`.
  * Эффект при наведении (`:hover`): подъем кнопки `transform: translateY(-2px)` и усиление свечения.

### 3.3 Интерактивный симулятор смартфона (`.phone-frame`)
* **Размеры:** Ширина `380px`, Высота `780px`, граница рамки корпуса `12px solid #1e293b`.
* **Dynamic Island (Вырез под камеру):**
  * Черный остров шириной `110px`, высотой `30px` с закругленными углами.
  * Пылающее фиолетовое размытие сзади выреза (`.phone-dynamic-island-glow`) имитирует нативное свечение экрана.
* **Нижняя панель навигации (`.phone-bottom-nav`):**
  * Позиционирована абсолютно внизу смартфона.
  * Полупрозрачный темный фон `rgba(10, 15, 30, 0.85)` с блюром `12px` и 5 кнопками переключения разделов.

### 3.4 Всплывающие уведомления (`success-toast`)
* **Свойства:**
  * Расположение: по центру сверху, закреплено (`position: fixed`).
  * Стилизация: заливка `rgba(6, 182, 212, 0.9)`, рамка `1px solid #06b6d4`, тень `0 4px 15px rgba(6, 182, 212, 0.4)` для создания сочного бирюзового свечения.

## 4. Сетка и Адаптивность (Layout & Responsiveness)

Макет EQUHUB оптимизирован для мониторов различного разрешения и мобильных устройств:

1. **Разрешения > 1400px (Desktop):**
   * Сетка на три колонки (`grid-template-columns: 1fr 420px 1.1fr`), где центральное место занимает смартфон-эмулятор, по бокам — панель управления и интерактивная карта архитектуры.
2. **Разрешения 1024px - 1400px (Medium):**
   * Автоматическая перестройка сетки на двухколонный макет. Панель управления и интерактивная схема занимают левую область, смартфон закреплен справа.
3. **Разрешения < 1024px (Mobile/Tablet):**
   * Элементы выстраиваются в вертикальную линию (`flex-direction: column`). Ширина смартфона и панелей масштабируется под размер экрана с максимальной шириной в `650px`.
