# EQUHUB — Единая цифровая платформа

## Документ 5: Дизайн-система (цвета, типографика, компоненты)

### 1. Цветовая палитра (CSS-переменные)

Дизайн-система EQUHUB основана на строгой темной неоновой схеме. Все стили импортируются и задаются через корневой файл `app/globals.css`:

| Переменная | Код цвета (HEX/RGBA) | Применение |
| :--- | :--- | :--- |
| `--bg` | `#05070f` | Основной глубокий темный фон приложения |
| `--surface` | `rgba(13, 20, 38, 0.7)` | Полупрозрачные карточки с эффектом размытия |
| `--surface-opaque` | `#0c101f` | Непрозрачный темный фон для выпадающих меню и форм |
| `--text` | `#f1f5f9` | Светло-серый контрастный текст для чтения |
| `--muted` | `#94a3b8` | Сдержанный серый текст для подзаголовков и подписей |
| `--accent-blue` | `#3b82f6` | Синий неон для ссылок, кнопок и переходов |
| `--accent-purple` | `#8b5cf6` | Фиолетовый неон для элементов социальной сети и AI |
| `--accent-cyan` | `#06b6d4` | Бирюзовый неон для раздела "Работа", Escrow и Кошелька |
| `--border` | `rgba(255, 255, 255, 0.08)` | Сверхтонкие границы для эффекта стекла |
| `--border-glow` | `rgba(139, 92, 246, 0.25)` | Фиолетовое неоновое свечение при наведении |
| `--shadow-glow` | `rgba(139, 92, 246, 0.15)` | Тень со свечением для кнопок и карточек |

### 2. Типографика

Используется кроссплатформенный гарнитурный шрифт **Inter** с системными фолбэками (`system-ui`, `-apple-system`, `sans-serif`).

*   **Заголовок H1 (Экранный):** 24px, жирный (`font-weight: 700`), межстрочный интервал `1.2`, цвет `--text`.
*   **Заголовок H2 (Разделы):** 18px, полужирный (`font-weight: 600`), межстрочный интервал `1.3`, цвет `--accent-cyan` или `--text`.
*   **Основной текст:** 14px (0.875rem), регулярный (`font-weight: 400`), межстрочный интервал `1.4`, цвет `--text`.
*   **Вспомогательный текст (Подписи):** 11px–12px, регулярный, цвет `--muted`.
*   **Текст терминала / Кода:** 10px–11px, `Courier New`, моноширинный.

### 3. Элементы интерфейса и Glassmorphism

#### 3.1. Стеклянная панель (Glass Panel)
Базовый контейнер для всех информационных блоков на платформе:
```css
.glass-panel {
  background: var(--surface);
  backdrop-filter: blur(16px);
  -webkit-backdrop-filter: blur(16px);
  border: 1px solid var(--border);
  border-radius: 24px;
  padding: 1.5rem;
  box-shadow: 0 8px 32px 0 rgba(0, 0, 0, 0.37);
  transition: border-color 0.3s ease, box-shadow 0.3s ease;
}
.glass-panel:hover {
  border-color: rgba(139, 92, 246, 0.3);
  box-shadow: 0 8px 32px 0 rgba(139, 92, 246, 0.1);
}
```

#### 3.2. Неоновая кнопка (Neon Button)
Используется для ключевых призывов к действию (CTA), например, подтверждения Escrow или пополнения баланса:
```css
.phone-btn-neon {
  background: linear-gradient(90deg, #3b82f6, #8b5cf6);
  border: none;
  border-radius: 10px;
  color: white;
  padding: 8px 12px;
  font-size: 12px;
  font-weight: 600;
  cursor: pointer;
  width: 100%;
  text-align: center;
  box-shadow: 0 4px 10px rgba(139, 92, 246, 0.25);
  transition: opacity 0.2s, transform 0.1s;
}
.phone-btn-neon:hover {
  opacity: 0.9;
}
.phone-btn-neon:active {
  transform: scale(0.98);
}
```

#### 3.3. Теги и Пилюли (Glass Pills)
Компактные информационные плашки для отображения категорий, статусов или геопозиции:
```css
.glass-pill {
  background: rgba(255, 255, 255, 0.05);
  border: 1px solid rgba(255, 255, 255, 0.08);
  border-radius: 20px;
  padding: 4px 10px;
  font-size: 10px;
  color: #fff;
  display: inline-flex;
  align-items: center;
  gap: 5px;
}
```

### 4. Адаптивная верстка и брейкпоинты

Приложение отлично масштабируется от мобильных экранов до широких 4K мониторов благодаря гибкой сетке CSS Grid:
*   **Десктопы (ширина > 1400px):** 3-колоночный лейаут (Панели управления | Симулятор Смартфона | Схема Архитектуры).
*   **Планшеты (ширина 1024px–1400px):** 2-колоночный лейаут (Левая колонка сжимает панель управления и схему, правая колонка удерживает телефон).
*   **Мобильные устройства (ширина < 1024px):** 1-колоночный вертикальный стек. Все панели и симулятор телефона выстраиваются друг под другом на 100% ширины экрана.
