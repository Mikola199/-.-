# 10. Руководство Администратора и Разработчика EQUHUB

## 10.1 Руководство разработчика (Developer Onboarding)

### Системные требования
- **Node.js**: `v18.x` или `v20.x`
- **Python**: `v3.12+`
- **Docker & Docker Compose**: Для работы локальных инстансов PostgreSQL 15, Redis 7 и Elasticsearch 8.

### Локальное развёртывание окружения

```bash
# 1. Клонирование репозитория
git clone https://github.com/Mikola199/neo-marketplace.git
cd neo-marketplace

# 2. Установка зависимостей Node.js
npm install

# 3. Проверка типов TypeScript
npx tsc --noEmit

# 4. Запуск локального веб-сервера разработки Next.js
npm run dev
```

Приложение станет доступно по адресу: `http://localhost:3000`.

## 10.2 Руководство администратора (Admin Panel Guide)

Панель администратора EQUHUB предоставляет инструменты управления инфраструктурой и модерации контента:

### Управление пользователями и правами (RBAC)
- **Супер-администратор (SuperAdmin)**: Полный доступ ко всем микросервисам, логам СУБД и транзакциям Кошелька.
- **Модератор (Content Moderator)**: Просмотр жалоб, модерация объявлений маркетплейса и публикаций социальной сети.
- **Арбитр Escrow (Escrow Specialist)**: Разрешение споров между покупателями и продавцами, принятие решений о возврате средств.

### Мониторинг шины логов
Интерактивный консольный терминал в реальном времени транслирует метрики и логи от микросервисов (`Auth Service`, `Payment Service`, `Chat Service (Go/C++)`, `AI Service`).
