# UML-диаграммы модулей и сервисов EQUHUB

Настоящий документ содержит спецификацию UML-диаграмм взаимодействия микросервисов и внутренней структуры системы, соответствующий разделу 3 и 15 Спецификации Требований (SRS).

---

## 2. Диаграмма последовательности: Создание и проведение безопасной сделки (Escrow)

Процесс взаимодействия Покупателя, Продавца, Маркетплейса, Кошелька и Системы уведомлений:

```text
Покупатель (User)       API Gateway        Payment Service      Escrow Ledger       Продавец (User)
       |                     |                     |                  |                     |
       |--- 1. Создать сделку -->                  |                  |                     |
       |    (POST /api/escrow)|                    |                  |                     |
       |                     |--- 2. Инициировать ->                  |                     |
       |                     |    Escrow сделку ---|                  |                     |
       |                     |                     |--- 3. Заморозить |                     |
       |                     |                     |    средства ---->|                     |
       |                     |                     |<-- 4. Подтвердить|                     |
       |                     |<-- 5. Статус OK ----|                  |                     |
       |<-- 6. Оплачено -----|                     |                  |                     |
       |                     |                     |                  |                     |
       |                     |                     |-- 7. Push-уведомление отправлено ------>|
       |                     |                     |   "Товар оплачен. Готовьте к отправке"  |
       |                     |                     |                  |                     |
       |                     |                     |                  |   8. Отправка товара|
       |                     |                     |                  |   и подтверждение   |
       |                     |<-- 9. Товар отправлен (POST /api/ship) |---------------------|
       |<-- 10. Статус "В пути"                    |                  |                     |
       |                     |                     |                  |                     |
       |-- 11. Подтвердить получение ------------->|                  |                     |
       |   (POST /api/receive)                     |                  |                     |
       |                     |                     |-- 12. Выплата ----------> [Кошелек]    |
       |                     |                     |   продавцу ------>                  |
       |<-- 13. Сделка завершена ------------------|                  |                     |
```
