# 4. Полный дизайн экранов в Figma (EQUHUB)

Данный документ описывает структуру, макетную сетку, иерархию слоев и дизайн-концепции для всех 16 экранных разделов платформы **EQUHUB**, спроектированных в Figma в соответствии с разделом 11 SRS.

---

## 4.1 Архитектура экранов и Figma-страницы

Проект в Figma разделен на 4 основных фрейма (Artboards) по целевым платформам:
1. **[Page 1] Mobile Apps (Flutter)** — Разрешение 393 x 852 px (iPhone 15).
2. **[Page 2] Web Frontend (Next.js)** — Разрешение 1440 x 900 px (Desktop).
3. **[Page 3] Admin Panel** — Разрешение 1920 x 1080 px (Desktop Dashboard).
4. **[Page 4] Design System Tokens & Components** — Цвета, шрифты, иконки, интерактивные состояния кнопок.

---

## 4.2 Описание 16 экранных разделов (Section 11)

### 4.2.1 Splash (Экран загрузки)
*   **Визуальный стиль:** Глубокий темный фон (`#030610`), в центре — неоновый 3D-логотип EQUHUB с радиальным градиентом и размытием (Backdrop Blur: 40px). Текст под логотипом: "Единая цифровая платформа".
*   **Скелет макета:**
    *   `[L1] Logo Container` (Center)
    *   `[L2] Spinner / Loading Indicator` (Bottom, 20% margin)

### 4.2.2 Login (Вход в систему)
*   **Скелет макета:**
    *   Заголовок: "С возвращением в EQUHUB" (Font-weight: Bold, Size: 24px).
    *   Поля ввода: Email, Пароль (с кнопкой "Показать пароль"). Скругление 12px, обводка `#1e293b`.
    *   Кнопка "Войти" (Неоновый градиент от голубого к фиолетовому, тень с размытием).
    *   Ссылка: "Забыли пароль?" и "Создать аккаунт".

### 4.2.3 Registration (Регистрация)
*   **Скелет макета:**
    *   Поля ввода: Имя, Фамилия, Email, Телефон, Пароль, Подтверждение пароля.
    *   Чекбокс: "Я согласен с условиями конфиденциальности и использования платформы".
    *   Кнопка "Зарегистрироваться" (активна только при заполненных полях и установленном чекбоксе).

### 4.2.4 Home (Главная страница)
*   **Скелет макета (Мобильный):**
    *   Header: Аватар пользователя (u1), Логотип EQUHUB, иконка Уведомлений с красной точкой-бэйджем.
    *   Stories: Горизонтальный список круглых аватарок с неоновой обводкой (активные прямые эфиры и видеоролики).
    *   Лента сообществ: Карточки рекомендуемых сообществ с кнопкой "Вступить".

### 4.2.5 Feed (Лента публикаций)
*   **Скелет макета:**
    *   Поле быстрого создания поста: "Что у вас нового, Екатерина?". Иконки прикрепления фото, видео и тегов.
    *   Посты: Карточка публикации (Аватар, Имя автора, Текст, Картинка-вложение, Панель реакций: Лайки, Комментарии, Репосты).

### 4.2.6 Marketplace (Маркетплейс)
*   **Скелет макета:**
    *   Поисковая строка с автодополнением и фильтром городов.
    *   Горизонтальный скролл категорий: "Все", "Техника", "Авто", "Недвижимость", "Услуги", "Хобби" с неоновыми иконками.
    *   Сетка товаров: 2 колонки на мобильном, 4 на десктопе. Карточка товара содержит фото, цену, заголовок, город, оценку безопасности ИИ (`ai_score`).

### 4.2.7 Product Card (Карточка товара)
*   **Скелет макета:**
    *   Слайдер фотографий (S3/MinIO).
    *   Блок цены и названия: "MacBook Pro M3 Max 16”" — 320,000 ₽.
    *   Блок продавца: Имя, Рейтинг (4.95 ⭐), Количество успешных сделок, Кнопки: "Написать продавцу", "Купить с безопасной сделкой" (яркая неоновая кнопка с иконкой замка).
    *   Подробное текстовое описание, прошедшее AI-модерацию.

### 4.2.8 Chat (Интерактивный диалог)
*   **Скелет макета:**
    *   Шапка чата: Имя собеседника ("Илья (Продавец)"), статус "В сети" / "Печатает...", кнопка "Видеозвонок".
    *   Тред сообщений: Выравнивание сообщений пользователя по правому краю (в синем градиенте), собеседника — по левому краю (темно-серые плашки с размытием).
    *   Нижняя панель: Поле ввода, кнопка отправки (Иконка ракеты 🚀), прикрепление файлов.

### 4.2.9 Video (Короткие видео и звонки)
*   **Скелет макета:**
    *   Вертикальный скролл видео в стиле TikTok/Reels.
    *   Правая панель инструментов поверх видео: Лайк, Комментарий, Поделиться, Профиль автора.
    *   Режим WebRTC-видеозвонка: Картинка во весь экран (собеседник), маленький плавающий прямоугольник в углу (собственная веб-камера), нижняя панель управления (выключить звук, отключить видео, завершить звонок ❌).

### 4.2.10 Wallet (Внутренний кошелек)
*   **Скелет макета:**
    *   Виртуальная дебетовая карта "EQUHUB PAY" с балансом в рублях (крупный шрифт: 450,000 ₽) и статусом "JWT Сессия Активна".
    *   Кнопка "Пополнить баланс через СБП".
    *   Список последних транзакций (Пополнение, Замораживание в Escrow, Разблокирование средств) с цветовой кодировкой: зеленый (+), красный (-), голубой (холдировано).

### 4.2.11 AI (Помощник ассистент)
*   **Скелет макета:**
    *   Интерактивная панель ввода промпта.
    *   Разделы автоопределения:
        *   Планшет "Рекомендуемая категория": Автоматически загорается нужная плашка.
        *   Панель "AI-Модерация": Статус безопасности (зеленый щит "Разрешено" или красный крест "Блокировка").
        *   Поле "Генеративный текст": Рекламное описание для товара или вакансии.

### 4.2.12 Notifications (Центр уведомлений)
*   **Скелет макета:**
    *   Список карточек уведомлений с фильтрами по типам: "Все", "Сделки", "Вакансии", "Чаты".
    *   Интерактивные кнопки прямо в уведомлениях (например, "Подтвердить получение товара").

### 4.2.13 Search (Глобальный поиск)
*   **Скелет макета:**
    *   Поисковая строка во весь экран.
    *   Поиск по карте (интегрированная интерактивная SVG-геокарта с метками объявлений и вакансий).
    *   Блок "Недавние поиски" и "Рекомендованное на основе ИИ".

### 4.2.14 Profile (Профиль пользователя)
*   **Скелет макета:**
    *   Большая обложка и аватар соискателя/продавца.
    *   Блок счетчиков: Публикации, Избранное, Подписчики, Звезды рейтинга.
    *   Вкладки: "Мои объявления", "Опыт работы/Резюме", "Обо мне".

### 4.2.15 Settings (Настройки аккаунта)
*   **Скелет макета:**
    *   Разделы: Безопасность (Смена пароля, Вход по 2FA, Сессии устройств), Конфиденциальность, Уведомления, Язык.

### 4.2.16 Admin Panel (Панель Администратора)
*   **Скелет макета:**
    *   Боковое меню: Модерация объявлений, Логи аудита, Управление жалобами, Аналитика.
    *   Графики активности пользователей, транзакций Escrow, рынка вакансий.
    *   Таблица жалоб (`Reports`) с кнопками "Заблокировать контент" и "Отклонить жалобу".

---

## 4.3 Сетка и адаптивное поведение (Responsive Breakpoints)

*   **Mobile Grid:** 4 колонки, Margin: 16px, Gutter: 12px.
*   **Desktop Grid:** 12 колонок, Margin: 80px, Gutter: 24px. Максимальная ширина контента: 1280px.
*   **Стекломорфизм (Glassmorphism):**
    *   `Background: rgba(13, 20, 38, 0.4)`
    *   `Backdrop Blur: 12px`
    *   `Border: 1px solid rgba(255, 255, 255, 0.06)`
